# 浏览器 WebAssembly 前端

这个页面不连接后端。牌面文本、CSV、牌靴状态、策略参数和回放结果都只存在于
当前浏览器标签页，核心计算由本项目的 Rust 库编译成 WebAssembly 后执行。

## 构建

在项目根目录运行：

```powershell
.\web\build.ps1
```

脚本会生成 `web/pkg/`。这个目录是构建产物，不需要手工修改。

## 本地打开

浏览器不能直接通过 `file://` 加载 WebAssembly 模块，需要本地 HTTP 服务：

```powershell
.\web\serve.ps1
```

然后打开：

```text
http://localhost:8000
```

## 输入语义

- `已消耗的牌`：先创建完整牌靴，再扣除输入牌；留空表示完整牌靴。
- `当前剩余的牌`：输入列表就是牌靴中的全部剩余牌，不能只列出其中一部分。
- 牌面格式：`AS`、`10H`、`KD`；可用空格、换行、中英文逗号、分号或顿号分隔。
- 页面默认使用 0.9% 返水。庄/闲下注遇和局没有返水；和注、大小和其他边注在赢、输或 Push 时都按实际下注额返水。
- 自动策略会比较闲、庄、和、任意对子、庄对、闲对、完美对子、大、小、幸运 6、幸运 7、超级幸运 7、庄龙宝和闲龙宝。
- 主注和边注可以使用不同最低有效 EV；边注的策略 EV、凯利金额与真实回放结算都会包含返水，并有独立单笔金额上限。
- 幸运 7 与超级幸运 7 使用各赔付档位的完整结果分布计算凯利比例，不使用平均赔率近似。
- “允许同局多下注”关闭时只执行最高有效 EV 目标；开启时所有达到各自门槛的目标都会执行，并共享本金比例、单局、桌台和本金总风险上限，超出时按比例缩小。

## 下注金额策略

下注方向始终先通过最低 EV 门槛，金额策略只负责决定“通过以后下多少”：

- `完整凯利`、`半凯利`、`四分之一凯利`：按收益分布计算完整凯利比例，再乘以 1、1/2 或 1/4。
- `自定义分数凯利`：自己填写完整凯利的缩放百分比，例如 30% 表示三成凯利。
- `固定金额`：每次尝试下注同一个金额。
- `固定本金比例`：每次按当时本金的一定百分比下注，因此本金变化后金额也会变化。
- `目标期望盈利`：用“目标盈利金额 / 有效 EV”反推下注额；有效 EV 不为正时不下注。
- `目标波动率`：根据该下注收益分布的标准差反推下注额，让单笔理论波动约占本金的指定比例。

所有金额仍会依次受到最大本金比例、单局金额、桌台金额和边注金额上限约束。
项目没有加入马丁格尔、斐波那契等追损策略，因为它们不会提高一笔下注本身的 EV，
只会让连续亏损时的金额和爆仓风险快速增大。

## 二十一点动作分析

- 切换到“21 点”后，可输入本手前已消耗牌，或输入扣除三张可见牌后的全部未知剩余牌。
- 当前桌规为美式暗牌与 Peek，支持 1～8 副、S17/H17、3:2/6:5 和晚投降切换。
- 页面比较停牌、补牌、加倍、分牌和投降；庄家 A 明牌时另外输出保险 EV。
- 未知庄家暗牌真实占用牌靴，A/十点明牌 Peek 后按“庄家没有 Blackjack”的条件计算。
- 动作 EV 以已经投入的原始底注 1 单位计量；加倍和分牌会显示还需追加的一个底注。
- 当前 Split 使用单手有限牌靴边际 EV × 2 的透明估算，尚未精确联合枚举两手互相耗牌与再次分牌。
- 当前 CSV 是百家乐字段，尚不支持 21 点回放；需要真实 21 点动作与结算字段后再接入。

## CSV 策略回放

- 必需列：`__source_pk`、`table_id`、`session_id`、`round_no`、`started_at`、
  `settled_at`、`raw_cards`、`result_code`。
- 只有从第 1 局开始、局号连续、牌面和结果均可验证的牌靴会参与回放。
- 回放按开局时间使用一份共享滚动本金；每局先比较十四种目标（三种主注加十一种边注）并计算金额，再用真实结果结算主注或边注，最后扣牌。
- 十一种边注都可独立设置“最后可下注局数”：填 0 不限制；填 N 时，第 1 至 N 局参与策略，从第 N+1 局起在 EV 比较前移除该玩法。默认大/小为 20（第 21 局起禁用），超级幸运 7 为 30（第 31 局起禁用），完美对子为 45（第 46 局起禁用），其余当前支持边注为 50（第 51 局起禁用）。
- 可设置“允许同局多下注”：开启后同一局可能生成多笔主注/边注，所有下注会同时结算并分别写入明细。
- 回放结果还会统计模拟期间最高本金、模拟最大盈利、最低本金、最大单笔下注和最大单局下注；最大盈利定义为“最高本金 − 初始本金”，最大单局下注是同一局所有下注金额的合计。
- 回放结果按庄、闲、和及十一种边注分别展示真正执行的下注笔数，所有分类相加应等于“实际下注”总数。
- 本金变化折线图卡片始终显示，未回放时会提示先上传 CSV；完成回放后按真实下注结算局展示滚动余额，同局多注合并为一个点。大量数据只在绘制时做保留峰谷的抽样，悬停信息和下注明细仍使用完整数据。
- 大型回放在 Web Worker 中执行，不阻塞页面输入。
- 回放报告保留全部真实下注明细；页面默认每页显示 500 笔，可切换每页数量并翻到末页查看完整数据。
