# 随机百家乐 CSV 生成器

项目现在提供 `generate_baccarat_csv` 命令，用完整牌靴生成符合当前网页回放格式的随机数据。

## 快速生成

在项目根目录运行：

```powershell
cargo run --release --bin generate_baccarat_csv -- docs/csv/random-baccarat.csv --shoes=100 --rounds-per-shoe=60 --seed=20260902
```

这条命令会生成：

- 100 靴牌；
- 每靴 60 局，共 6,000 局；
- 每靴使用 8 副完整扑克牌；
- 使用固定种子 `20260902`，以后使用相同参数可重现完全相同的数据；
- CSV 只包含 `session_id`、`round_no`、`raw_cards` 三列；
- 输出文件可以直接上传到“CSV 策略回放”。

## 可配置参数

| 参数 | 默认值 | 作用 |
| --- | ---: | --- |
| `--shoes` | 100 | 生成多少靴牌 |
| `--decks` | 8 | 每靴使用几副牌，允许 1～8 |
| `--rounds-per-shoe` | 60 | 每靴生成多少局 |
| `--seed` | 20260902 | 随机种子；相同种子产生相同 CSV |
| `--start-session-id` | 1000000 | 第一靴的场次编号 |

例如，生成 1,000 靴、每靴 55 局的数据：

```powershell
cargo run --release --bin generate_baccarat_csv -- docs/csv/random-55000.csv --shoes=1000 --rounds-per-shoe=55 --seed=42
```

生成文件的表头固定为：

```csv
session_id,round_no,raw_cards
```

其中 `session_id` 是牌靴编号，`round_no` 是该牌靴内从 1 开始的子局数，
`raw_cards` 是庄闲双方的真实牌面。回放时不需要额外提供开奖结果，Rust 会从
牌面重新计算结果，避免随机文件同时保存两份可能互相矛盾的信息。

## 为什么这份数据符合百家乐

生成器不是直接随机填写“庄、闲、和”，而是先创建具体的 52 种牌并按副牌数复制，然后执行 Fisher–Yates 洗牌。每局都从当前牌靴无放回取牌，并复用项目已有的闲家和庄家补牌规则。

写入 CSV 前，生成器还会把牌序列交给正式的 `resolve_round()` 再验证一次。只有牌数、发牌顺序、补牌规则和开奖结果完全一致才会写入。因此对子、完美对子、大小、幸运 6/7 和龙宝等玩法也能根据具体牌面正常结算。

## 使用随机数据时要注意

随机数据适合验证代码、下注策略、资金曲线和统计指标是否正确，但不能证明真实赌场中可以稳定盈利。真实数据还可能包含切牌位置、不同桌台规则、取消局、数据缺失和人为行为等随机生成器没有模拟的因素。
